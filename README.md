## Cara Menjalankan

1. Cek kesiapan environment:

   ```bash
   flutter doctor
   ```

2. Masuk ke direktori proyek minggu yang dituju (contoh minggu 1):

   ```bash
   cd 01-week-1-mobile-development-ecosystem-flutter-refresh/my_first_app
   ```

3. Pasang dependensi lalu jalankan:

   ```bash
   flutter pub get
   flutter run
   ```
